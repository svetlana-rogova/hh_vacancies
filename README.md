# Проект hh_vacancies
## Описание:
Данный проект позволяет найти подходящие по описанию вакансии с сайта HeadHunter. В нем расположены классы и функции, 
которые позволяют фильтровать вакансии по названию, описанию, городу, зарплате, валюте и выдают список из выбранного 
количества вакансий, подходящих по описанию расположенных по убыванию зарплаты. Также можно найти вакансии по названию 
и записать их в файл. После этого можно добавить новую вакансию в файл, удалить ее или очистить весь файл целиком. Также
в проекте находится функционал, позволяющий сравнивать несколько вакансий по зарплате. 
## Установка и использование:
1. Откройте PyCharm
2. Клонируйте репозиторий:
```
git clone https://github.com/svetlana-rogova/hh_vacancies
```
3. Установите зависимости через Poetry:
```
poetri install
```
4. Активируйте виртуальное окружение:
```
poetry shell
```
5. В модуле getting_data_API.py находится класс, который подключается к API сайта HeadHunter и записывает данные по 
нужным вакансиям в файл, путь к которому можно указать при вызове метода класса.
6. В модуле job_comparison.py представлен класс для основных характеристик вакансии. В нем проводятся все проверки 
данных по вакансии, а также методы, которые позволяют сравнивать несколько вакансий между собой по зарплате.
7. В моделе working_file.py представлен класс для сохранения информации о вакансиях в JSON-файл. В нем находятся методы
для добавления информации в файл, для получения информации по критериям из файла, для удаления всей информации из файла 
и для удаления определенной вакансии из файла по id
8. В модуле utils.py находятся функция, которая приводят данные, полученные с сайта по API в понятный человеку формат. 
Также в этом модуле находятся дополнительные функции для обработки данных по вакансиям по полученной информации от 
пользователя.
## Тестирование:
Все тесты лежат в директории tests/, имена модулей начинаются с test_.
В данной директроии реализованы тесты для каждого модуля из пакета src/.
Для запуска тестирования необходимо установить pytest:
```
poetry add --group dev pytest
```
Запустить тесты можно через команду pytest в терминале:
```
pytest
```
Чтобы проверить покрытие файла тестами нужно установить petest-cov в отдельную группу:
```
poetry add --group dev pytest-cov
```
Проверить покрытие можно через команду:
```
poetry run pytest --cov
